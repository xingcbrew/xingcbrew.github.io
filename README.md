# xingcbrew.github.io

Free learning tools and games by Xing Brew, hosted with GitHub Pages.

| Project | Address | What it is |
|---|---|---|
| Homepage | `/` | Links to everything below |
| Math Blocks | `/mathblocks.html` | Block-building math game: a free pattern playground plus addition, subtraction, multiplication and division challenges. Best for ages 6-8. |
| Name Creations | `/name-creations/` | Generate names in ASL fingerspelling and Braille. Includes a class-list mode with ZIP and PDF download. |

## Layout

- `index.html`: homepage
- `mathblocks.html`: Math Blocks (one self-contained file)
- `name-creations/`: the ASL/Braille generator, its About page, and the `asl/` and `braille/` letter images
- `assets/`, `images/`: shared styles, scripts and images (Phantom template by HTML5 UP)
- `numberblocks.html`, `ispad_tool.html`, `ispad/`, `PSO/`, `YouthREX/`: other project files, not linked from the homepage

## Notes

Pages inside `name-creations/` reach the shared files with `../assets/` and `../images/`.
